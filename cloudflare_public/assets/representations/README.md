# DharmaCodex Representation Scaffold v0.1

Static scaffold for future public-safe symbolic graphics.

This folder does not contain final renderers, runtime calculations, DB access, or system readings. It only defines shared visual tokens and a minimal static map shape that can be used later by approved renderers.

## Public-Safe Token Scope

- coordinate
- focus
- numerology signal
- matrix signal
- astrology signal
- human design protected signal

## Guardrails

- No DB connection.
- No backend.
- No calculated astrology wheel.
- No protected Human Design reading.
- No identity labels from protected systems.
- No protected internal source fields.
